# 目标

把科目二 TD3 的动作从“转向、油门/刹车轴、挡位”三个连续量，收敛为“转向、纵向意图”两个连续量；同时修正车辆参考点混用问题，并以固定考试车和 GA 1029—2022 场地尺寸重新做几何可行性验收。

# 当前核对结论

## 已确认正确

- 倒车入库库长 `4.473 + 0.7 = 5.173 m`、库宽 `2.3 m`、车道宽 `6.7 m`、库位到控制线 `6.7 m`，与 GA 1029—2022 表 3 的小型载客汽车尺寸一致。
- 当前虚拟前轮最大转角 `0.58 rad = 33.23°`。按当前轴距/轮距换算，后轴中心最小半径约 `3.89 m`，外侧前轮转弯直径约 `10.51 m`，与同级考试车常见的约 `10.7 m` 接近。因此“角度太小”不是首要根因。
- 现有几何回放测试可以把车倒入库，证明场地并非数学上无解；但该测试复制了当前积分公式，不能证明公式本身正确。

## 必须修正

- 车辆常量混用了两代车型：`4.473 × 1.706 m` 是新桑塔纳量级车身，代码轴距却是老车型量级的 `2.548 m`；同一组车身参数应统一校准为一辆明确的考试车，轴距先按 `2.603 m` 复核，轮距和前后悬继续以原厂资料落定。
- 状态中的 `(x, y)` 被碰撞和绘制当作“车身中心”，但航向公式 `v / wheelBase × tan(steer)` 是以后轴中心为参考点的公式，位置却仍沿车身朝向推进。满舵时缺少车身中心应有的侧偏运动（当前参数约 `18.1°`），车身扫掠轨迹因此不可信。
- 现有可行性测试自己重写了同一套简化公式。新验收必须直接调用生产积分器，并独立测量转弯直径、四角扫掠包络和全程最小边线净距。

## 关于前驱/后驱

低速、无轮胎侧滑的科目二几何中，决定路径的是“前轮转向 + 后轮滚动约束”，前驱或后驱只影响牵引力和打滑，不改变理想几何轨迹。当前模型的意图确实是前轮转向，但参考点实现不一致；v3 先修正运动学，不引入对低速教学无收益的轮胎滑移模型。

# 交互原型

## TD3 动作（3 维 → 2 维）

```text
action[0] steer               -1 左满舵 ── 0 回正 ── +1 右满舵
action[1] longitudinalIntent  -1 反向意图 ── 0 滑行/保持 ── +1 正向意图
```

纵向意图不是第三个挡位，也不是分别输出油门和刹车。环境按当前速度解释它：

| 当前状态 | 与当前运动同号 | 0 | 与当前运动反号 |
|---|---|---|---|
| 静止 | 选择该方向并从 0 连续加速 | 保持静止 | 选择该方向并从 0 连续加速 |
| 正在前进/倒车 | 连续增加该方向速度 | 滑行/坡度作用 | 只减速，最低到 0，不在同一物理步穿零反向 |
| 刚减到 0 | 下一物理步才允许重新选择前进或倒车 | 保持静止 | 下一物理步才允许重新选择前进或倒车 |

解释规则：静止时纵向意图的正负选择前进/倒车；运动时，同号是加速、异号是减速。车辆可在任意速度转向。坡道的重力回溜仍保留，因为那是外力，不是模型偷偷换挡。

## 页面状态

- “模型输出”只显示：`转向 −100…100%`、`纵向意图 −100…100%`。
- “车辆响应”显示：`实际速度 km/h`、`运动方向 前进/静止/倒车`、`纵向状态 加速/滑行/减速/坡道回溜`。
- 删除训练界面的油门、刹车、挡位三个模型输出读数；内部限加速度、限减速度、坡度力仍作为物理说明展示，不再由 TD3 分别操控。
- 桌面端沿用现有高密度实验台层级；移动端两项模型输出和实际速度纵向排列，不新增弹窗或遮罩。

# 车辆运动学方案

1. 用一致的真实车型参数定义车长、车宽、轴距、前后轮距和后轴到车身中心的距离。
2. 生产状态仍对外提供车身中心，内部每步先换算到后轴中心，以前轮转向的运动学自行车模型积分，再还原车身中心供碰撞、传感器和渲染使用。
3. 最大转角不直接沿用 `0.58`，而由原厂最小转弯直径反算并以仿真测量回归；预期仍约 `33°`，只有证据显示偏差时才改变。
4. 2D 车辆视图中的前轮按实际转角显示，后轮保持不转向；驱动轴不作为低速几何变量。驾驶员 3D 视角按已提出的整站瘦身方案另行删除。

# 模型与存档迁移

- 动作维度从 3 变 2 会改变 actor 输出层和 critic 输入层，v2 权重无法无损加载为 v3。
- 使用新的 localStorage key 和 checkpoint schema v3；不覆盖、不删除旧 v2 存档。
- 首次进入时明确提示“旧三动作模型已保留但与双动作模型不兼容”，v3 从新模型开始训练。不得静默加载形状不一致的权重。

3. 样例通过后扩展运行时、探索策略、奖励平滑项、遥测、存档版本和页面文案。
4. 运行全量 test/lint/build，并在真实桌面与移动视口检查训练、评估、刷新和旧存档提示。

# 验收标准

- TD3 模型元数据明确显示 `actionSize = 2`，页面无可由模型直接操控的油门/刹车/挡位。
- 任何一个物理步都不能把正速度直接变成负速度，或把负速度直接变成正速度。
- 满舵实测外侧前轮转弯直径与选定考试车原厂数据误差不超过 `±0.15 m`。
- 倒车入库可行性测试直接调用生产积分器；从固定起点到整车入库全程不碰线、不出场，且记录最小净距。
- 2D/3D 中仅前轮转向，车辆四角轨迹与碰撞几何使用同一车身中心位姿。
- v2 存档仍留在浏览器中，v3 不会误读；v3 自动保存、刷新恢复和评估模式可用。
- 全量测试、lint、类型检查、构建通过；本地真实浏览器桌面/移动布局和关键交互通过后，才进入发布步骤。

# 已确认的设计决定

按上述“二轴动作”语义实现：第二个输出是**有方向的纵向意图**，而不是可瞬间跳变的目标速度。这样既符合“连续加减速、到零后才能换向”，也保留加速度、坡度和制动距离。

# 完成证据
