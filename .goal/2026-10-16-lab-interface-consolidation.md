# 目标

把实验室从“教学说明、实时画面、诊断卡片同时争夺注意力”的长页面，重构为适合长时间训练观察的统一工作台。保留 Q-learning、DQN 单车、TD3 科目二三个实验；完整移除 TD3 城市出租车车队实验与专属实现。

# 统一信息架构

三个保留实验共享同一层级：

1. **顶栏**：实验切换、训练/评估、运行速度、开始/暂停、模型保存状态。
2. **主观察区**：单一主画布；不再同时展示多个相似视图。
3. **长期证据区**：累计回报、成功/完成率、损失或价值稳定性；默认占页面主要宽度。
4. **关键读数**：固定最多四项，因算法不同替换内容但位置一致。
5. **原理与诊断抽屉**：公式、单步证据、奖励分解、终止明细、模型参数、存档管理。

# 桌面原型（≥1024px）

```text
┌ 实验切换 ──────────────── 训练/评估  1× 4× 16× MAX  开始/暂停  ●已保存 ┐
├───────────────────────────────┬───────────────────────────────────┤
│                               │  长期训练趋势                     │
│          主观察画布           │  回报 ─────────────────────      │
│     （唯一场景/地图视图）     │  成功率 ───────────────────      │
│                               │  损失/价值 ─────────────────      │
├───────────────────────────────┴───────────────────────────────────┤
│ step 128k │ 成功 63% │ 当前动作 -0.28/+0.61 │ 当前奖励 +0.14       │
├───────────────────────────────────────────────────────────────────┤
│ 失败分布 / 分科表现                  [原理与诊断] [模型与存档]     │
└───────────────────────────────────────────────────────────────────┘
```

- 主观察区与长期曲线首屏同时可见，建议 `5:7` 宽度。
- 曲线共享时间轴，可单独开关序列；不使用多张等权卡片。
- 顶栏控件只保留会改变训练或观察窗口的选择。

# 各实验长期曲线

| 实验 | 主曲线 | 次曲线 | 长期判据 |
|---|---|---|---|
| Q-learning | episode return | 成功率、步数、TD error | 是否稳定找到安全路径而非只看单格闪烁 |
| DQN 单车 | episode return | 成功率、loss、epsilon | Replay 预热后是否收敛且失败类型下降 |
| TD3 科目二 | episode return | 分科完成率、critic/actor loss | 五项是否同时改善，碰线/出界/停滞是否下降 |

统一窗口：`最近 1k`、`最近 10k`、`全部`。训练数据采用固定桶聚合，页面只保留可视化所需摘要，避免无限增长 DOM 或数组。

# 视觉与交互约束

- 沿用 `design.md`：冷灰白底、白色面板、琥珀强调、12px 面板圆角、8px 控件圆角，不引入新风格。
- 不再用大量等权卡片；主画布和长期曲线构成唯一一层主层级。
- 训练复位不出现遮罩或弹窗；状态变化用顶栏文字和曲线断点表达。
- 所有图表同时提供当前值与趋势摘要；颜色之外用标签/线型区分。
- 尊重 `prefers-reduced-motion`，训练渲染继续使用 RAF 抽样，不让图表每个物理步重排。

# 代表性样例与扩展顺序

1. 先在 TD3 科目二完成统一布局样例：删除 3D、单主画布、长期曲线、四项读数和抽屉。
2. 在 1440、1024、768、320px 真实浏览器检查后，再把同一骨架扩展到 Q-learning 与 DQN。
3. 最后完整删除出租车实验及其零引用模块，避免一边迁移一边误删共享代码。

# 验收标准

- 三个保留实验的顶栏、主画布、长期曲线、关键读数和抽屉顺序一致。
- 1440×900 首屏同时看得到主画布、长期曲线和训练控制，不需向下滚动才找到趋势。
- 页面上不存在驾驶员主视角、Three.js 相机状态或重复场景视图。
- 长期曲线可切换 1k/10k/全部，并在长训练下保持固定数量渲染点。
- 出租车实验没有菜单/路由/代码/测试/资产/脚本/文档残留；保留实验构建和运行正常。
- 自动化测试、lint、类型检查和构建通过；真实浏览器桌面/移动截图、控制交互、控制台和性能检查完成后才允许发布。

# 待批准的界面决定

以“主画布 + 长期曲线并列”为桌面核心，所有教学说明、公式、详细诊断和模型存档降级到两个抽屉；不再在主流程中逐段展示教学卡片。
